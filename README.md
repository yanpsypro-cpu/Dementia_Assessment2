# Dementia risk factors and diagnostic reliability

R scripts supporting Statistics for Health Data Science, Assessment 2.

## Files

- `00_prepare.R`: imports the assessment data, checks identifiers, missing values and coding, defines factors and the complete-case analysis sample.
- `q1_descriptive.R`: descriptive statistics, Table 1 and distribution plots.
- `q2_hdl_smoking.R`: HDL comparisons across smoking groups, diagnostics, pairwise comparisons and sensitivity analyses.
- `q3_dementia.R`: logistic regression, model selection, odds ratios, exploratory checks, forest plot and age-specific prevalence.
- `q4_diagnosis.R`: diagnosis cross-tabulation, accuracy measures with exact binomial intervals, and predictive-value scenarios.
